# Unit 4 — Aggregate Functions & GROUP BY

## Overview
This unit focuses on SQL aggregate functions and grouping data using `GROUP BY`.

## Objectives
- Use `SUM()` to calculate totals
- Use `AVG()` to calculate averages
- Use `COUNT()` to count records
- Use `MAX()` to find the highest value
- Use `MIN()` to find the lowest value
- Use `GROUP BY` to summarize data by category
- Create a revenue summary

## Database Used
- Database: `store`
- Table: `order_items`

## Queries Practiced

1. Total revenue using `SUM()`
2. Average unit price using `AVG()`
3. Total order items using `COUNT()`
4. Highest unit price using `MAX()`
5. Lowest unit price using `MIN()`
6. Total quantity sold by product using `GROUP BY`
7. Revenue summary by product using `GROUP BY` and `ORDER BY`
